Overlay configuration (MERIDIAN_CONFIG)

Every knob of the overlay's spec §2.1 constants. Values are prefilled from the page's URL params (gossipMs / stun / turn / mediaSrc), applied when you press Connect, and locked afterwards: reload the page to change them.

Empty STUN falls back to the library default; an empty TURN list means no relay. The media source row is display-only — it is chosen by the ?mediaSrc= URL param.

Connect

The signaling server is only a rendezvous: peers swap each other's contact info through it, then all media and data flow peer-to-peer over WebRTC.

Actions

"Find closest node" floods a routed query over the rings and returns the lowest-RTT peer that answers (up to maxHops hops, accepted once the routeAcceptanceThreshold fraction of queried rings replied). "Stream to peer" asks that peer for its media and renders it below. Both take a full peer id.

Peer inspector

Live view of the node's knownPeers table, sorted by ring: ring 0 is the closest latency band, outer rings widen by the multiplicative factor. Refreshes every second.
